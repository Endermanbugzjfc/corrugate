# Navigate the terminal's retained conversation using anchors

Corrugate leaves Codex unmodified and uses Kitty's scrollback and remote-control commands.
Stable visible markers are the default; unique normalized explanation text is an experimental
alternative. Physical line numbers cannot survive wrapping or pane resizing. A saved board is
durable, but navigation is available only when the attached terminal retains the explanation.
An explicit attachment resolves uncertain terminal identity rather than guessing the active tab.
There is no launcher or permanent watcher: publishing opens the viewer on demand.
